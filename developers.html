Plan Maestro developer resources

Recursos públicos para agentes y desarrolladores. La API de este sitio es de solo lectura y no pide credenciales.

OpenAPI

La especificación de la API pública está en https://plan-maestro.com/openapi.json. Describe GET /api/v1/health y GET /api/v1/site.

API catalog

El catálogo RFC 9727 está en https://plan-maestro.com/.well-known/api-catalog. Apunta a la especificación OpenAPI y a esta página.

Errores

Los errores de la API usan RFC 9457 application/problem+json. Cada cuerpo incluye type, title, status, detail, instance, code y hint. El campo hint indica la especificación OpenAPI. Un método distinto de GET responde 405 con el encabezado Allow: GET. Una ruta /api desconocida responde 404.

Autenticación

Esta API no usa clave, registro ni OAuth. El ingreso a Plan Maestro PRIME es con cuenta de Google en https://prime.plan-maestro.com y no forma parte de este contrato.
