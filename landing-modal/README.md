- **Diseño minimalista** con gradientes modernos

- **Efectos visuales** como partículas flotantes y parallax
- **Responsive design** que se adapta a todos los dispositivos

- Estadísticas y métricas en tiempo real

#### 📖 Base de Datos Educativa
- Base de datos curricular extensa

## 🎨 Personalización

Para personalizar la landing page:

1. **Colores**: Modifica las variables CSS en `:root`
2. **Animaciones**: Ajusta las duraciones en las clases CSS
3. **Contenido**: Edita el HTML para cambiar textos y funcionalidades
4. **Efectos**: Modifica o desactiva efectos en `script.js`
