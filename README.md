# 🎓 Plaɳ MaeŠtrɸ - Landing Page Moderna

Una landing page moderna y atractiva para la plataforma educativa Plaɳ MaeŠtrɸ, diseñada específicamente para docentes uruguayos.

## ✨ Características Principales

### 🎨 Diseño Moderno
- **Diseño responsivo** que se adapta a todos los dispositivos
- **Gradientes modernos** y efectos visuales atractivos
- **Tipografía optimizada** con fuentes Inter y Poppins
- **Animaciones suaves** con AOS (Animate On Scroll)
- **Efectos hover** interactivos en todos los elementos

### 🚀 Funcionalidades Avanzadas
- **Preloader animado** con efecto de carga
- **Navegación suave** entre secciones
- **Navbar dinámico** que cambia al hacer scroll
- **Contadores animados** para estadísticas
- **Efecto parallax** en la sección hero
- **Botón de WhatsApp flotante** con animación
- **Botón "Volver arriba"** automático

### 📱 Experiencia de Usuario
- **Navegación intuitiva** con menú hamburguesa en móviles
- **Carga optimizada** con lazy loading de imágenes
- **Accesibilidad mejorada** con ARIA labels
- **Performance optimizada** con debouncing de eventos
- **SEO friendly** con metadatos apropiados

## 🛠️ Tecnologías Utilizadas

### Frontend
- **HTML5** - Estructura semántica moderna
- **CSS3** - Variables CSS, Flexbox, Grid, Animaciones
- **JavaScript ES6+** - Funcionalidades interactivas
- **Bootstrap 5** - Framework CSS responsivo
- **Font Awesome 6** - Iconografía moderna
- **AOS Library** - Animaciones al hacer scroll

### Características Técnicas
- **CSS Variables** para consistencia de diseño
- **Flexbox y Grid** para layouts modernos
- **Intersection Observer API** para animaciones
- **Debouncing** para optimización de performance
- **Smooth scrolling** nativo del navegador

## 🚀 Cómo Usar

### Instalación Local
1. Clona o descarga el proyecto
2. Abre `index.html` en tu navegador
3. ¡Disfruta de la experiencia moderna!

### Personalización
- Modifica las variables CSS en `:root` para cambiar colores
- Actualiza las imágenes en `assets/images/`
- Edita el contenido en `index.html`
- Ajusta las animaciones en `modern-script.js`

## 🔧 Personalización

### Cambiar Colores
```css
:root {
    --primary-color: #tu-color;
    --secondary-color: #tu-color;
    /* ... */
}
```

### Modificar Animaciones
```javascript
AOS.init({
    duration: 800,        // Duración
    easing: 'ease-in-out', // Tipo de easing
    once: true,           // Una sola vez
    mirror: false         // Sin espejo
});
```

### Agregar Nuevas Secciones
1. Añade la estructura HTML en `index.html`
2. Define los estilos en `modern-style.css`
3. Agrega funcionalidades en `modern-script.js`
